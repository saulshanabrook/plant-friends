# Header, installation, download priority and ETA verification

This slice keeps the pinned catalog/model/photo releases and scoring unchanged. It removes top section navigation, shortens product copy, links BioCLIP 2/PFAF provenance, moves Add app to the header, and replaces the leaf artwork with scripted black PF text on white. Detection uses standalone display mode, appinstalled and optional same-app related-app results; a dismissed or accepted prompt alone does not assert installation. Browser support remains best effort. Installation fallback help appears only on request.

Reference metadata, native image URLs and the bulk queue now wait for a compatible saved model. Cached photos remain intact; model-ready offline metadata/inventory restoration is covered, including an initially hidden page. The new aggregate ETA includes future catalog/model/image/index bytes; cached inventory jumps never establish speed. It requires five seconds, multiple network increments and 64 KiB, forgets interrupted/hidden/offline/stalled rates, and rounds coarsely. Compressed catalog/index payload rates are not projected onto uncompressed model/WebP transfers; image transfer starts a fresh rate stage. Future uninspected caches conservatively count as remaining, and later request/cache overhead can change the estimate.
